# Домашняя работа — вариант 13

CLI-транслятор учебного конфигурационного языка в YAML. Используется только
стандартная библиотека Python.

## Запуск

```bash
cd ~/GITHUB/configuration-management/homework-v13

python3 -m src.main \
  --input examples/server.conf \
  --output result.yaml
```

Параметры:

- `--input` — путь к исходному файлу учебного языка;
- `--output` — путь к создаваемому YAML-файлу.

## Поддерживаемые конструкции

Комментарий:

```text
NB. комментарий до конца строки
```

Числа, массивы и вложенные словари:

```text
{
  number: -12.5;
  values: (list 1.0 2.0 3.0);
  nested: { value: 4.0; };
}
```

Константы объявляются перед итоговой конфигурацией:

```text
base: 9.0
{
  sum: .[+ base 1].;
  root: .[sqrt(base)].;
  biggest: .[max 1.0 base 4.0].;
}
```

По спецификации обычные числовые значения имеют дробную часть. Целые числа
допускаются внутри константных выражений, поскольку такой пример прямо приведён
в задании: `.[+ имя 1].`.

Поддерживаются операции времени трансляции:

- `+` — ровно два аргумента;
- `sqrt` — один неотрицательный аргумент;
- `max` — один или несколько аргументов.

Выражения вычисляются во время преобразования, поэтому в YAML записывается уже
готовое число.

## Примеры

В папке `examples` находятся две предметные области:

- `server.conf` — конфигурация сервера;
- `experiment.conf` — конфигурация физического эксперимента.

Для каждого входного файла сохранён ожидаемый `.yaml`.

## Обработка ошибок

Синтаксические ошибки содержат строку и столбец:

```text
syntax error: строка 1, столбец 14: ожидалось ';'
```

Проверяются недопустимые символы, незакрытые конструкции, неправильные числа,
повторные имена, неизвестные константы, количество аргументов функций и
математические ошибки.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты покрывают комментарии, числа, массивы, словари, вложенность, константы,
сложение, `sqrt`, `max`, YAML, CLI, ошибки и оба предметных примера.
