# Практическая работа №2 — вариант 13

Инструмент визуализации графа зависимостей пакетов Ubuntu (`apt`). Программа
самостоятельно загружает и разбирает индекс `Packages`, строит граф
рекурсивным DFS и выводит его на языке D2 и в виде ASCII-дерева.

Готовые пакетные менеджеры и сторонние библиотеки для получения зависимостей
не используются. Проект работает только на стандартной библиотеке Python.

## Быстрый запуск

Все команды выполняются из папки практической работы:

```bash
cd ~/GITHUB/configuration-management/prac2-v13
```

### Тестовый репозиторий

```bash
python3 -m src.main \
  --package A \
  --repository examples/test_repository.txt \
  --test-mode \
  --version 1.0 \
  --ascii-tree \
  --max-depth 5
```

Результат:

```text
D2:
direction: right
"A" -> "B"
"A" -> "C"
"B" -> "D"
"C" -> "A"
"C" -> "D"
"D" -> "E"

ASCII tree:
A
├── B
│   └── D
│       └── E
└── C
    ├── D [already shown]
    └── A [cycle]
```

`[already shown]` означает общую зависимость, которая уже была раскрыта в
другой ветви. `[cycle]` обозначает циклическую зависимость.

### Настоящий Ubuntu-репозиторий

На момент проверки в `noble-updates` доступна версия `curl`
`8.5.0-2ubuntu10.16`:

```bash
python3 -m src.main \
  --package curl \
  --repository https://archive.ubuntu.com/ubuntu \
  --version 8.5.0-2ubuntu10.16 \
  --ascii-tree \
  --max-depth 1
```

Пример результата:

```text
ASCII tree:
curl
├── libc6
├── libcurl4t64
└── zlib1g
```

Репозитории обновляются, поэтому старая версия пакета может исчезнуть из
текущего индекса. В этом случае программа сообщает, что заданная версия не
найдена: это ожидаемая обработка ошибки.

## Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `--package` | Имя анализируемого пакета |
| `--repository` | URL Ubuntu-репозитория или путь к тестовому файлу |
| `--test-mode` | Использовать тестовый файл вместо настоящего репозитория |
| `--version` | Точная версия пакета |
| `--ascii-tree` | Дополнительно вывести ASCII-дерево |
| `--max-depth` | Максимальное число переходов по зависимостям |

Флаги `--test-mode` и `--ascii-tree` имеют значение `True`, если они указаны,
и `False`, если отсутствуют. Глубина `0` оставляет в графе только исходный
пакет.

Справка:

```bash
python3 -m src.main --help
```

## Формат тестового репозитория

Каждая строка имеет вид `ПАКЕТ: ЗАВИСИМОСТЬ1, ЗАВИСИМОСТЬ2`. Имена состоят из
больших латинских букв:

```text
A: B, C
B: D
C: D, A
D: E
E:
```

Такой пример содержит ветвление, общую зависимость `D` и цикл `C -> A`.

## Как работает программа

1. `argparse` читает и проверяет параметры командной строки.
2. В обычном режиме программа формирует URL индекса Ubuntu `Packages.xz`.
3. `urllib` загружает индекс, а `lzma` или `gzip` распаковывает его.
4. Собственный парсер читает поля Debian Control: `Package`, `Version`,
   `Pre-Depends` и `Depends`.
5. Выбирается именно версия, переданная через `--version`.
6. Рекурсивный DFS строит транзитивный граф до `--max-depth`.
7. Активный стек DFS обнаруживает циклы и предотвращает бесконечную рекурсию.
8. Граф преобразуется в текст D2 и, при наличии `--ascii-tree`, в дерево.

Для альтернативной зависимости `a | b` учебная программа выбирает первый
вариант. Квалификаторы архитектуры и ограничения версий удаляются из имени
узла графа.

## Выполненные этапы

### Этап 1. CLI и конфигурация

Добавлены все шесть параметров, вывод `ключ: значение` и обработка ошибок.
Результат зафиксирован коммитом `1bf4462`.

### Этап 2. Сбор данных

Реализованы загрузка Ubuntu `Packages`, поиск точной версии и получение прямых
зависимостей без `apt` и сторонних библиотек. Коммит `dea5838`.

### Этап 3. Граф зависимостей

Граф строится рекурсивным DFS с ограничением глубины. Поддерживаются циклы и
тестовый файл с пакетами `A`, `B`, `C`. Коммит `599dfd1`.

### Этап 4. Порядок загрузки

Используется постфиксный DFS: зависимость добавляется раньше пакета, который от
неё зависит. Общие узлы не повторяются, циклы не вызывают зацикливание. Коммит
`2e85b9c`.

### Этап 5. Визуализация

Финальная версия всегда выводит D2. ASCII-дерево выводится только с флагом
`--ascii-tree`. Коммит `7c86f61`.

## Примеры для трёх пакетов

```bash
python3 -m src.main --package A --repository examples/test_repository.txt --test-mode --version 1.0 --ascii-tree --max-depth 5
python3 -m src.main --package B --repository examples/test_repository.txt --test-mode --version 1.0 --ascii-tree --max-depth 5
python3 -m src.main --package C --repository examples/test_repository.txt --test-mode --version 1.0 --ascii-tree --max-depth 5
```

Краткие результаты:

```text
A: ветвление A -> B, C; общая зависимость D; цикл C -> A
B: B -> D -> E
C: C -> D -> E и C -> A -> B; цикл A -> C
```

## Сравнение со штатными средствами apt

На Ubuntu прямые зависимости можно посмотреть командой:

```bash
apt-cache depends curl
```

План установки:

```bash
apt install --simulate curl
```

Штатное описание графа Graphviz DOT:

```bash
apt-cache dotty curl
```

Результаты могут различаться. Учебная программа выбирает первую альтернативу
и учитывает только `Pre-Depends` и `Depends`. `apt` дополнительно учитывает
архитектуру, виртуальные пакеты, рекомендации, конфликты, уже установленные
пакеты и использует полноценный решатель зависимостей. Наша программа выводит
D2 и ASCII, тогда как `apt-cache dotty` формирует Graphviz DOT.

## Обработка ошибок

Программа завершает работу с кодом `2` и понятным сообщением, если:

- пропущен обязательный параметр;
- имя обычного или тестового пакета имеет неправильный формат;
- версия содержит недопустимые символы;
- URL не использует `http` или `https`;
- тестовый файл отсутствует или имеет неправильный формат;
- глубина отрицательная или не является целым числом;
- пакет или его точная версия отсутствует в индексе;
- индекс невозможно загрузить, распаковать или прочитать;
- передана неизвестная опция или значение после логического флага.
