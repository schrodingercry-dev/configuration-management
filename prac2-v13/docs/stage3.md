# Этап 3. Основные операции

Граф строится рекурсивным обходом в глубину (DFS). Параметр `--max-depth`
ограничивает число переходов от исходного пакета. Активный стек DFS позволяет
обнаружить цикл и не войти в бесконечную рекурсию.

Тестовый репозиторий — текстовый файл со строками вида `A: B, C`. Согласно
заданию все тестовые пакеты называются большими латинскими буквами.

```bash
python3 -m src.main \
  --package A \
  --repository examples/test_repository.txt \
  --test-mode \
  --version 1.0 \
  --max-depth 4
```

Пример содержит ветвление, общую зависимость и цикл `C -> A`.
