# Этап 4. Порядок загрузки

Порядок строится постфиксным DFS: пакет добавляется в результат только после
его зависимостей. Общие зависимости включаются один раз, а активный стек
защищает обход от циклов.

Для примера `A -> B -> C` результат будет `C, B, A`.

## Сравнение со штатным менеджером

Результат можно сопоставить с `apt-cache depends <пакет>` и планом установки
`apt install --simulate <пакет>`. Наш инструмент показывает детерминированный
постфиксный порядок одного выбранного варианта зависимости. `apt` может дать
другой результат, потому что дополнительно учитывает уже установленные пакеты,
архитектуру, виртуальные пакеты, конфликты, рекомендации и выбирает подходящую
альтернативу с помощью решателя зависимостей.
