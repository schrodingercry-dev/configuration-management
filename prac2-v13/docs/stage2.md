# Этап 2. Сбор данных

Программа напрямую загружает индекс `Packages`, распаковывает `.xz` или `.gz`
средствами стандартной библиотеки Python и разбирает поля Debian Control.
Пакетные менеджеры и сторонние библиотеки не используются.

Можно передать прямой URL файла `Packages`, `Packages.gz`, `Packages.xz` или
корень официального Ubuntu-репозитория. Для корня программа последовательно
проверяет индексы Ubuntu 24.04 LTS (`noble`) для `main` и `universe`.

На этом этапе выводятся только прямые `Pre-Depends` и `Depends` выбранной
версии. Для альтернативы `a | b` выбирается первый вариант — так формируется
однозначный граф для следующих этапов.
